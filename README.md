WhatBytes Product Store
A responsive e-commerce product listing application built for the WhatBytes Frontend Developer Assignment.

🚀 Features
- Responsive product listing
- Product search
- Category & price filtering
- URL-based filters
- Dynamic product detail pages
- Add to cart
- Update/remove cart items
- Cart persistence with LocalStorage
- Responsive header and footer
🛠️ Tech Stack
- Next.js
- React
- JavaScript / JSX
- Tailwind CSS
- React Context API
- Lucide React
- LocalStorage
